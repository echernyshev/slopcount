# Conventions

## Код
- src-layout, ruff line-length 100, target py311; наборы E/W/F/I/UP/B/SIM/C4/RUF;
  RUF001-003 отключены (кириллица = ложные срабатывания).
- Язык исходников и комментариев — преимущественно русский (докстринги/комментарии),
  идентификаторы английские.

## i18n (gettext) — критичные нюансы
- Английский — язык исходников: msgid = английский текст в `_()`; en работает без каталога.
- `i18n.setup()` ДО любого `_()` (глобальное состояние); conftest.py сбрасывает в en autouse-фикстурой.
- Плюрализация только `ngettext`; интерполяция только `%`-стиль (msgfmt проверяет плейсхолдеры).
- Числа — `fmt_int`/`fmt_float` (en `,.` / ru ` ` `,`).
- **Ключи JSON/CSV не локализуются никогда** — стабильны для CI между языками.
- Каталоги фраз детекции (`rules/phrases_*.toml`) ортогональны локали UI; описания правил проходят `_()` при загрузке.
- Битый пользовательский `--rules` TOML → RuntimeError → exit 2; битый встроенный — fail fast.

## Известные приближения — не «чинить» молча
- Незакрытый docstring, `/* */` не с начала строки (задокументированы в докстринге `extractors.py`).
- Сканер: `.gitignore` без отрицаний `!` — осознанное упрощение.

## Perplexity-режим
- Замер контекстный (GPTZero-стиль): один проход, пер-токенный NLL, группировка по предложениям
  через offset mapping; первое предложение отбрасывается; порог медиана < 40.
- Длинные файлы — по префиксу окна; предупреждение токенизатора глушится хирургическим фильтром логгера.
